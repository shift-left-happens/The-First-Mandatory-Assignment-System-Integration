# Advantages

- Language agnostic
- Standard Graph Query Language
- Granularity when fetching, easy nesting
- No versioning
- Less latency than REST (1 request for element composed of 5 elements, compared to 5 with rest?)
- Fragments for reuseability
- GraphQL Unions


SDL (Schema Definition Language)
Contains objects (! means non-null)

# Disadvantages
- Caching can be harder
- Learning curve
- Complex to implement
- Nesting can be problematic
- Not RESTful but uses POST?
- Missing support outside Javascript
